Most posts should just be Markdown, but sometimes you already have a fragment of hand-written HTML — an embed, a table with rowspans, whatever Markdown is bad at — and don't want to fight a converter.

Drop a .html file in content/ next to a same-named .json file for its metadata, and the build will pass the HTML straight through into the article template untouched.

ApproachWhen to use it
Markdown + frontmatterAlmost always
Raw HTML + JSON sidecarEmbeds, complex tables, one-offs
